# Keyboard Navigator

Chromeブラウザでキーボードだけでウェブページをナビゲートできる拡張機能です。Vimライクなキーバインドで快適なブラウジング体験を提供します。

## 特徴

- マウス不要のキーボード操作
- Vimライクな直感的なキーバインド
- リンクヒントモードで素早くリンクをクリック
- ページ内検索機能
- 軽量でシンプル

## インストール方法

1. Chromeで `chrome://extensions/` を開く
2. 右上の「デベロッパーモード」を有効にする
3. 「パッケージ化されていない拡張機能を読み込む」をクリック
4. このディレクトリを選択

## 使い方

### スクロール操作

| キー | 動作 |
|------|------|
| `j` | 下にスクロール |
| `k` | 上にスクロール |
| `d` | 半ページ下にスクロール |
| `u` | 半ページ上にスクロール |
| `gg` | ページトップへ移動 |
| `G` | ページボトムへ移動 |

### ナビゲーション

| キー | 動作 |
|------|------|
| `H` | 戻る（ブラウザの戻るボタン） |
| `L` | 進む（ブラウザの進むボタン） |
| `r` | ページをリロード |

### リンクヒントモード

| キー | 動作 |
|------|------|
| `f` | リンクヒントモードを起動 |
| `数字` | 表示された番号を入力してリンクをクリック |
| `Esc` | リンクヒントモードを終了 |

**使い方:**
1. `f` キーを押す
2. ページ内のクリック可能な要素に番号が表示される
3. 目的のリンクの番号を入力
4. 自動的にそのリンクがクリックされる

### 検索・フォーカス

| キー | 動作 |
|------|------|
| `/` | 検索モードを起動 |
| `i` | 最初の入力フィールドにフォーカス |

**検索モードの使い方:**
1. `/` キーで検索ボックスを表示
2. 検索ワードを入力してEnterキーを押す
3. 検索結果が黄色でハイライト表示される
4. 現在フォーカス中の結果はオレンジ色で表示
5. `↑`/`↓` キーで検索結果間を移動
6. `Ctrl + Enter` でフォーカス中の検索結果が含まれるリンクを新しいタブで開く
7. `Esc` で検索モードを終了

### その他

| キー | 動作 |
|------|------|
| `Esc` | 現在のモードを終了 |

## 注意事項

- 入力フィールドやテキストエリアにフォーカスがある場合、キーボードショートカットは無効になります
- 一部のWebサイトでは、サイト独自のキーバインドと競合する可能性があります
